# Architecture Decision Records (ADRs)

Los ADRs documentan decisiones de arquitectura importantes: el contexto, la
decisión tomada y sus consecuencias.

| ADR | Título | Estado |
|-----|--------|--------|
| [ADR-008](./ADR-008-kafka-en-produccion.md) | Apache Kafka como bus de eventos | Aceptado |

> Los ADR-001 a ADR-007 corresponden a decisiones previas (stack del monólito,
> bases de datos, Keycloak, arquitectura hexagonal, Next.js, etc.) y se
> documentarán progresivamente.
